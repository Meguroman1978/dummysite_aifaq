# Cloudflare Pages Build Settings

This file documents the correct build settings for Cloudflare Pages deployment.

## Build Configuration

Use these settings in the Cloudflare Pages dashboard:

| Setting | Value |
|---------|-------|
| **Framework preset** | None |
| **Build command** | (Leave empty) |
| **Build output directory** | `public` |
| **Root directory (advanced)** | `/` |
| **Environment variables** | None required |

## Important Notes

- **Do NOT use wrangler CLI** for Cloudflare Pages deployment
- The `functions/` directory will be automatically detected and deployed as Cloudflare Workers Functions
- Static files in `public/` will be served via Cloudflare CDN
- No build step is needed as this is a pure Node.js application with static frontend

## Deployment Method

This project uses **Cloudflare Pages Git Integration** (not Wrangler CLI):
1. Connect GitHub repository to Cloudflare Pages
2. Set build output directory to `public`
3. Leave build command empty
4. Cloudflare will automatically serve static files and deploy functions

## Why No Build Command?

This project doesn't require a build step because:
- Frontend files are already in `public/` directory
- No transpilation needed (vanilla JavaScript)
- No CSS preprocessing
- Backend logic is in `functions/` (automatically deployed)
