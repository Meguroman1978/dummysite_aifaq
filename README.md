# ウェブサイト複写＆スクリプト埋め込みツール

## 概要
このツールは、実在するウェブサイトを複写し、好きな位置にFirework AIFAQスクリプトを埋め込むことができるWebアプリケーションです。

## 注意事項
⚠️ **重要**: このツールは自分が所有するウェブサイト、または明確な許可を得たウェブサイトでのみ使用してください。他人のウェブサイトを無断でコピーすることは著作権侵害やフィッシング詐欺と見なされる可能性があります。

## 主な機能
- ✅ ウェブサイトのURL入力と取得
- ✅ CORS制限を回避するプロキシサーバー
- ✅ **画像プロキシ機能** - CORS制限された画像もBase64変換で取得
- ✅ ビジュアルな位置選択（クリックで埋め込み位置を指定）
- ✅ Firework AIFAQスクリプトの自動埋め込み
- ✅ リアルタイムプレビュー
- ✅ 修正されたHTMLのダウンロード
- ✅ **詳細なエラーメッセージ** - 問題を特定しやすいエラー表示

## 技術スタック
- **バックエンド**: Node.js + Express
- **フロントエンド**: HTML5, CSS3, JavaScript (Vanilla)
- **依存パッケージ**:
  - express: Webサーバー
  - cors: CORS対応
  - axios: HTTP通信
  - cheerio: HTML解析とURL変換

## セットアップ

### 前提条件
- Node.js (v14以上)
- npm

### インストール
```bash
# 依存関係をインストール
npm install
```

### 起動方法
```bash
# サーバーを起動
npm start
```

サーバーが起動すると、`http://localhost:3000` でアクセスできます。

## 使い方

### 1. URLとIDを入力
- **ウェブサイトURL**: 複写したいウェブサイトのURL（例: `https://example.com`）
- **Domain Assistant ID**: FreshworksのドメインアシスタントID

### 2. ウェブサイトを取得
「ウェブサイトを取得」ボタンをクリックして、指定したウェブサイトを読み込みます。

### 3. 埋め込み位置を選択
プレビュー画面で、スクリプトを埋め込みたい要素をクリックします。
- マウスホバーで要素がハイライト表示されます
- クリックすると確認ダイアログが表示されます

### 4. HTMLをダウンロード
スクリプトが埋め込まれた完成版のHTMLファイルをダウンロードできます。

## 埋め込まれるコード
```html
<script async type="text/javascript" src="https://asset.fwscripts.com/js/ava.js?business_id=g201J5"></script>
<fw-ava
    domain_assistant_id="あなたのID"
    layout="faq"
></fw-ava>
```

## API エンドポイント

### POST /api/fetch-website
ウェブサイトのHTMLを取得し、相対URLを絶対URLに変換します。

**リクエスト**:
```json
{
  "url": "https://example.com"
}
```

**レスポンス**:
```json
{
  "success": true,
  "html": "<!DOCTYPE html>...",
  "baseUrl": "https://example.com"
}
```

## トラブルシューティング

### ウェブサイトが取得できない
- CORS制限が厳しいサイトは取得できない場合があります
- タイムアウト（10秒）を超えるサイトは失敗します
- HTTPSが必須のサイトは、HTTPでアクセスできません

### プレビューが正しく表示されない
- JavaScriptに依存するサイトは完全に動作しない場合があります
- 一部のCSSやリソースが読み込めない可能性があります

### スクリプトが埋め込めない
- iframe内のセキュリティ制限により、一部のサイトでは動作しない場合があります

## 技術的な制限
- **Same-Origin Policy**: iframeのセキュリティ制限により、一部のサイトはプレビューできません
- **JavaScript実行**: 動的にコンテンツを生成するサイトは正しく表示されない場合があります
- **外部リソース**: 一部のCSSや画像が読み込めない可能性があります
